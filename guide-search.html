enot621 - Search Guide

Hello! You're probably here because you want to know how to search! Even though it's quite stupid, you can use this page to figure out exactly how searching works, and how you can word your searches to get your desired posts.


When searching, you can search for a single tag such as inv. This will search for any post that has the tag inv in its tags or metadata.

You can search for multiple tags such as inv and plushie. This will search for any post that has both of the tags.

Additionally, you can search by file name and file format. Such as: inv and .gif. This will look for any tags tagged inv and are in the GIF file format.
